# Commit rules

- Commit functional changes separately.
- Write commit messages in English using [Conventional Commits 1.0.0](conventional-commits.md).
- Start the description with an imperative verb and limit it to 72 characters.

## Format and examples

Use `<type>: <description>` or `<type>(<scope>): <description>`.

```text
feat(ui): standardize buttons and enforce shared component reuse
fix(oauth): respect provider support for the openid scope
```
